# Data Sources

## Dataset 1: Occupational Employment and Wage Statistics (OEWS)

**Source Organization:** U.S. Bureau of Labor Statistics (BLS)

**Dataset Name:** Occupational Employment and Wage Statistics (OEWS) - Metropolitan and Nonmetropolitan Area Estimates

**Download Date:** 06/08/2026

**Files Downloaded:**

* MSA_M2025_dl.xlsx
* BOS_M2025_dl.xlsx
* file_description.xlsx

**Primary File for Analysis:**

* MSA_M2025_dl.xlsx

**Purpose:**
This dataset provides occupation-level employment and wage estimates for metropolitan areas in the United States. It will be used to analyze technology occupations, employment levels, wage trends, and regional concentration of tech jobs within the Bay Area.

**Key Fields:**

* area_title
* occ_code
* occ_title
* tot_emp
* loc_quotient
* h_mean
* a_mean
* h_median
* a_median

**Notes:**

* MSA_M2025_dl.xlsx will serve as the primary dataset.
* BOS_M2025_dl.xlsx contains Balance of State estimates and is not currently planned for analysis.
* file_description.xlsx contains metadata and field definitions.
